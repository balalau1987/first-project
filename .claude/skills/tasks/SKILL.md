# Задачи: личные и рабочие

Два файла, никогда не смешивать:
- `tasks/personal.md` — дом, семья, здоровье, покупки, хобби, личные финансы, друзья.
- `tasks/work.md` — проекты, встречи, коллеги, клиенты, рабочий код, отчёты.

## Добавить задачи
1. Разбить сообщение на отдельные задачи (одна строка — одна задача).
2. Для каждой решить: личная или рабочая. Признаки работы: клиент, коллега, встреча, созвон, проект, отчёт, дедлайн по работе. Если неясно — спросить одним вопросом сразу про все неясные задачи, не угадывать.
3. Срок перевести в дату `ГГГГ-ММ-ДД` (и время, если есть), считая от сегодняшней даты: «завтра», «в пятницу», «через неделю».
4. Добавить в раздел «Сделать» нужного файла в формате:
   `- [ ] Текст задачи (срок: 2026-11-10 15:00)` — без срока часть в скобках не писать.
5. Не дублировать: если такая задача уже есть, обновить её, а не добавлять вторую.

## Изменить статус
- Начата → перенести в «В работе».
- Выполнена → `- [x]`, перенести в «Готово», дописать `(готово: ГГГГ-ММ-ДД)`.
- Удалить — только по прямой просьбе.

## Показать задачи
- «На сегодня» — задачи со сроком сегодня или просроченные, плюс всё «В работе».
- Выводить двумя блоками: **Личное** и **Работа**, просроченные — первыми с пометкой «просрочено».

## После изменений
Закоммитить файлы задач с коротким сообщением («Задачи: +3 личных, +1 рабочая») и запушить в рабочую ветку. В ответе пользователю кратко: что куда добавлено.
