# Проект «Вася Знает» — контекст для Claude Code

## О проекте
YouTube-канал про строительство. Персонаж — Дядя Вася, 50 лет, рассказывает про ошибки в стройке с юмором.
Видео без живого человека: ИИ-аватар + ИИ-голос. Форматы: Shorts (до 60 сек) и мини-сериалы / длинные разборы.
Фирменная концовка Shorts: «Я — Вася. Я знаю.»

## Железо и предпочтения
- Windows, видеокарта **RTX 3050** (мало VRAM, 4–8 ГБ): тяжёлые модели (Wan, HunyuanVideo, CogVideoX) локально не потянет.
  Тяжёлое — через Colab или бесплатные облачные сервисы. torch ставить с `cu121` (Ampere).
- Всё максимально бесплатно, качественно; делать **через код**, а не кликами. Интересны китайские open-source модели.

## Выбранный стек
| Этап | Инструмент |
|---|---|
| Сценарий | Claude |
| Голос | ElevenLabs API (10 000 симв/мес бесплатно); локально: Fish Speech, CosyVoice 2 |
| Аватар (фото + аудио → говорящее видео) | SadTalker / MuseTalk (Tencent) через Colab; HeyGen — только вручную (3 бесплатных видео) |
| B-roll (стройка, ошибки) | Kling AI, Hailuo, Vidu (бесплатные кредиты); Wan / CogVideoX через Colab |
| Монтаж | FFmpeg + MoviePy (через код), CapCut |
| Нарезка Shorts | OpusClip (60 мин/мес), open-source: Clipsai / AutoClip |
| Транскрипция чужих видео | yt-dlp + Whisper + Ollama (папка `vasya_pipeline/`) |

Пайплайн: сценарий → голос → аватар → B-roll → монтаж → нарезка Shorts.

## Референс
Файл HeyGen-Video (вертикальное 1080×1920, 32 сек) — образец: говорящий аватар. Цель — получать такое же без HeyGen.

## Сделано
- Написан первый сценарий Shorts про фундамент в ноябре (55 сек).
- В `vasya_pipeline/modules/` — черновики (не проверены): transcribe, analyze, subtitles, storyboard, animations.

## Следующие шаги
1. Получить API-ключ ElevenLabs (хранить в переменной окружения `ELEVENLABS_API_KEY`, не в коде/git).
2. Скрипт `tts.py`: текст → mp3 голосом Дяди Васи.
3. Фото Дяди Васи (анфас) → Colab-ноутбук SadTalker/MuseTalk → mp4.
4. Скрипт сборки на FFmpeg/MoviePy: аватар + B-roll + субтитры → Shorts 1080×1920.
