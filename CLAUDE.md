# Правила для Claude

## Задачи: личное и рабочее раздельно
- Личные задачи — только в `tasks/personal.md`.
- Рабочие задачи — только в `tasks/work.md`.
- Никогда не смешивать списки и не переносить задачи между ними без просьбы.
- Если непонятно, личная задача или рабочая, — спросить, а не угадывать.
- Формат задачи: `- [ ] Текст (срок, если есть)`; выполненные — `- [x]` в разделе «Готово».
