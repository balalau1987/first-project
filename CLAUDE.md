# Правила для Claude

## Перед началом работы
- Прочитать `WORKSPACE_INDEX.md`, чтобы выбрать правильный репозиторий и место для материалов.
- Для задач по сайту Работа Всем перейти в `balalau1987/rabota-cheboksary` и прочитать его `PROJECT_STATE.md` и `CLAUDE.md`.
- Не складывать код сайта в этот репозиторий: здесь находятся общие навыки Claude Code, каталог инструментов и списки задач.

## Задачи: личное и рабочее раздельно
- Личные задачи — только в `tasks/personal.md`.
- Рабочие задачи общего характера — только в `tasks/work.md`.
- Никогда не смешивать списки и не переносить задачи между ними без просьбы.
- Если непонятно, личная задача или рабочая, — спросить, а не угадывать.
- Формат задачи: `- [ ] Текст (срок, если есть)`; выполненные — `- [x]` в разделе «Готово».

## Скиллы и инструменты
- Каталог источников скиллов — `tools.md`. Когда задаче поможет скилл, сначала искать там (официальные — в приоритете).
- Установленные скиллы лежат в `.claude/skills/`. Скилл от сообщества ставить только после просмотра его файлов.

## Безопасность и публикация
- Не добавлять в Git секреты, токены, пароли, персональные данные и дампы баз.
- Не менять живой сайт и не выполнять деплой без отдельного явного согласия владельца на конкретное изменение.
- Не удалять и не перемещать существующие навыки и папки без необходимости.
